01

The problem

Designers and developers often struggle with fragmented icon libraries that lack consistency across platforms and design tools. Iconly Pro needed a scalable web platform for browsing and downloading icons, a desktop app for offline access, a Figma plugin in designers' workflows, a unified experience across every platform, and a maintainable architecture for continuous icon releases.

02

What I built

I built a unified ecosystem where designers could discover, preview, and use icons across multiple environments without disrupting their workflow: the Iconly Pro website, a Windows desktop application, a Figma plugin, reusable APIs shared across platforms, and optimised search and asset delivery.

  • Icon library website

    fast browsing, advanced search, category filtering, multiple export formats

  • Windows desktop app

    offline access, fast asset search, organised collections, quick export

  • Figma plugin

    browse icons in Figma, one-click insertion, search and filtering, live asset updates

  • Shared ecosystem

    consistent assets across platforms, shared APIs, unified UX, centralised content management
